# Discogs PHP

A modern, framework-agnostic and type-safe PHP client for the Discogs API.

> This package is in early development and does not have a stable release yet.

## Requirements

- PHP 8.3 or newer
- JSON extension
- A PSR-18 HTTP client
- PSR-17 HTTP factories

## Status

The first public release will initially support:

- database search;
- master releases;
- releases;
- consumer credentials;
- personal tokens;
- typed pagination;
- rate-limit information.
